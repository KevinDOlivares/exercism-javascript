# Exercism Solutions 💻

A clean repository containing my solutions to programming track exercises and challenges on [Exercism](https://exercism.org/).

The primary goal of this repository is to practice core language syntax, build strong problem-solving skills, write idiomatic code, and apply test-driven development (TDD) principles using local testing suites.

## 🧰 Tech Stack & Tools

* **Languages:** JavaScript (Node.js)
* **Testing:** Jest
* **Editor:** Visual Studio Code
* **Version Control:** Git & GitHub
